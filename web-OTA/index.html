用数据线连接开发板，然后任选一种：

      
    
        
  1. 
          espflash 命令行（推荐）
          
    cd ESP32_Firmware/rust/crates/firmware
cargo run --release
    
          等价于 espflash flash --monitor --chip esp32c3 --partition-table partitions_ota.csv <bin>。
          注意必须带 --partition-table，否则双槽分区表的偏移与固件不一致。
        
    2. 
        
  2. 
          浏览器直刷（esp-web-tools）：把编译产物和 manifest.json 放到同一个静态目录里
          （用 python -m http.server 8000 起服务即可，localhost 属于安全上下文），
          然后用 Chrome 打开 esp-web-tools 的刷写页并选择该 manifest。
          
    {
  "name": "CursorLight",
  "version": "V.rs0.4.1",
  "builds": [{
    "chipFamily": "ESP32-C3",
    "parts": [
      { "path": "bootloader.bin", "offset": 0 },
      { "path": "partitions.bin", "offset": 32768 },
      { "path": "boot_app0.bin",   "offset": 57344 },
      { "path": "cursorlight.bin", "offset": 65536 }
    ]
  }]
}
